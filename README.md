One original one-line excuse an AI agent gives for a missed deadline: it handed the deadline to a subagent, who handed it to another subagent, and the last one in the chain is still on page one of the brief. A deterministic program writes the line to `/output/entry.txt` — no network, no randomness, no timestamps.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
